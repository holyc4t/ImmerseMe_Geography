# ImmerseMe: Geography — design

Date: 2026-11-16 · Author: holyc4t · Status: draft for approval

## Intent

The second module of the ImmerseMe roleplay suite for WoW: Forever (interface 16001).
Weather tells you what the sky is doing. Geography tells you what the land is like:
what kind of country you are standing in, and, if you are a gatherer, what it holds.

It should feel like local knowledge, not a database. A miner who has worked the hills
"knows" the copper runs rich and the tin is thin. A novice has a hunch, and a veteran
knows for sure. Someone who never swung a pick knows nothing about ore at all.

## Goals

- A compact readout on the **upper-left** arc of the minimap, mirroring ImmerseMe:
  Weather's readout (which defaults to the lower-left arc).
- **Icons first, minimal text.** Terrain etc. are icons; at most one short word on screen.
- **Resources learned by gathering**, shown as name + level icon (e.g. `Copper ▲▲`, `Tin ▼`),
  never as raw numbers on the minimap.
- **Accuracy grows with skill.** Low skill: the level may be one step off and is marked uncertain.
  High skill: exact.
- **Profession-gated.** Ores only with Mining, herbs only with Herbalism, hides/game only with
  Skinning, fish only with Fishing. No profession → that category doesn't exist for you.
- **Tooltip holds the detail**: full names, worded levels, your personal gathering record.
- Same look and feel as Weather: Blizzard gold tooltip header, grey label / white value double
  lines, outlined `STANDARD_TEXT_FONT` readout that follows the minimap curve, custom TGA icons
  generated by a Python script in the stock-icon style.

## Non-goals

- Node locations, pins, routes or a gathering-node map (that's GatherMate's job).
- Any network sync between players.
- Localisation beyond English in v1 (zone names and item matching follow Weather: English zone
  names; resources matched by item ID so the loot side is locale-proof).

## Anti-goals (failure even if it "works")

- Turning into a numbers panel (percentages, node counts on the minimap).
- Revealing resources the player hasn't earned (no profession, never gathered there).
- Visual clutter that fights Weather's readout or the stock minimap buttons.
- Flicker: a level that changes on every /reload or every update tick.

## Approaches considered

| | Approach | Trade-off |
|---|---|---|
| A | Built-in "truth" table per zone, revealed by gathering; skill sharpens the reading | Consistent across players; needs authored zone data |
| B | Purely empirical: level = share of what you've gathered in the zone | Zero data, but "high" describes your habits, not the land; skill can't improve accuracy |
| **C** | **A + personal gathering record in the tooltip** | **Picked.** A's honesty on the minimap, plus a personal journal feel in the tooltip |

Chosen by the user: **C**.

## What gets shown

### Land (everyone sees this)

Four facets per zone, each one icon. Sub-zones may override any facet (a mine is underground,
a lakeside sub-zone has a lake).

| Facet | Values |
|---|---|
| Terrain | forest, grassland, hills, mountains, desert, badlands (canyon), swamp, jungle, tundra, coast, volcanic, blighted, underground, city |
| Ground underfoot | soil, mud, sand, rock, snow, ash, stone (paved/cave) |
| Water | river, lake, sea, marsh, none |
| Wildness | settled, frontier, wild |

Instances: terrain `underground`, others hidden (my call: mirrors Weather's instance handling).

### Resources (profession-gated, learned)

Categories and the profession that unlocks each:

| Category | Profession | Gather signal | Examples |
|---|---|---|---|
| Ore | Mining | loot after the Mining cast | Copper, Tin, Silver, Iron, Gold, Mithril, Truesilver, Thorium, Dark Iron, Incendicite, Lesser Bloodstone |
| Herb | Herbalism | loot after Herb Gathering | Peacebloom … Black Lotus |
| Hide | Skinning | loot after Skinning | Light / Medium / Heavy / Thick / Rugged Leather (grade of local game) |
| Fish | Fishing | loot after a fishing catch | the zone's catchable fish |

Levels: three tiers, each with its own small icon, worded in the tooltip:

| Tier | Minimap icon | Tooltip word |
|---|---|---|
| low | one small down-chevron / single pip, dim | Scarce |
| medium | two pips | Common |
| high | three pips / up-chevron, bright gold | Plentiful |

Uncertain readings (low confidence) show the tier icon desaturated/with a faint "?" mark;
tooltip word becomes "Common, perhaps".

### Minimap layout (sketch)

Rows right-aligned on the upper-left arc, same curve maths as Weather's `LayoutReadout`:

```
  [terrain][ground][water][wild] Hills     ← row 1: 4 icons + one word (terrain name)
                       Copper [▲▲▲]        ← resource rows, best first
                          Tin [▼]
                   Peacebloom [▲▲]
```

- Max **4 resource rows** on the minimap (configurable 0–6). Order: highest tier first, then the
  one you gathered most. The rest are in the tooltip.
- Short names on the minimap ("Copper", not "Copper Ore"; "Kingsblood"). Full name in tooltip.
- No resource rows at all if the player has no gathering profession.

## Discovery and accuracy model

**Ground truth**: `Data.lua` lists for each zone (and optional sub-zone) the resources and their
true tier. Shipped with the addon, same for everyone.

**Discovery**: a resource becomes known in a zone the first time the player loots that resource's
item from a gather in that zone. Stored per character.

**Gather detection**: track the last successful gathering cast (`UNIT_SPELLCAST_SUCCEEDED` for the
player, matched by spell ID for Mining / Herb Gathering / Skinning / Fishing); on `LOOT_OPENED`
within a few seconds of it, read `GetLootSlotLink` item IDs and match against the resource catalog.
Fishing catches come through the same loot window. Secondary drops (gems from veins, etc.) are
ignored unless in the catalog.

**Skill**: read from `GetSkillLineInfo` (character skill list), refreshed on `SKILL_LINES_CHANGED`.
Profession absent → category hidden entirely, including previously learned entries (they come back
if the profession is relearned; data is kept).

**Accuracy**: confidence for a resource = how far the player's skill is above that resource's
required skill, plus a little for how many times they've gathered it there.
- Confidence high → shown tier = true tier, no "?".
- Confidence low → shown tier may be off by one step, marked uncertain.
- Whether (and which way) a low-confidence reading is off is **deterministic** from
  character + zone + resource (hash, like Weather's `hash01`), so it never flickers and only changes
  when skill or gather count crosses a threshold.
- Exact formula and thresholds: builder's call, constraints: a just-learned resource at its minimum
  skill is uncertain; ~75 skill points above the requirement (or ~25 gathers there) is always exact.

**Hints**: at skill ≥ 225 (artisan-ish; builder may tune), if a zone has an undiscovered resource in
that profession that the player *could* gather, the tooltip shows one vague hint line. Never the name.

**Personal record** (the "C" part): per character, per zone, per resource: count gathered and
timestamp of last gather. Shown in the tooltip only.

## Data

- `Data.lua` (safe to tweak, like Weather's):
  - resource catalog: key → item ID(s), short name, full name, category, required skill, icon.
  - land facet catalog: key → label, icon.
  - `ns.Zones[zoneName]` = { terrain, ground, water, wild, flavour, resources = { copper = "high", ... } }
  - `ns.SubZones[subZoneName]` = partial overrides (facets and/or resources).
- Coverage v1: every zone in Weather's zone table (Eastern Kingdoms + Kalimdor vanilla zones),
  plus common mine/cave sub-zones. Resource tiers should match well-known Classic distributions.
- Unlisted zone: land facets from a sensible default (grassland/soil/none/wild) with no resources
  known in the truth table; anything gathered there is still recorded as learned with tier
  "medium/uncertain" (my call: B-style fallback so gathering is never silently lost).

### Calls settled after review (marked as builder/author calls, not user decisions)

1. **Zone vs sub-zone.** Discoveries are keyed by **zone** (`GetRealZoneText()`), with each gather
   also tagged with the sub-zone it happened in. A sub-zone entry in `ns.SubZones` **replaces** the
   zone's land facets that it names. If it lists resources, those **replace** the zone list while
   you stand inside it (a mine shows the mine). Counts and the "~25 gathers" rule are per zone,
   and the tooltip may break them down by sub-zone. CharDB shape:
   `chars.disc[zone][resKey] = { n = count, last = epoch, sub = { [subzone] = count } }`.
2. **Instances.** Resources **are shown and recorded** in instances (BRD, Maraudon, Dire Maul…),
   keyed by instance name, the same way as zones. `ns.Zones` may contain instance names. An
   instance with no entry uses the unlisted-zone fallback.
3. **Fish and hides.** Tier = how common that fish or leather grade is in the zone. Confidence is
   measured against a **per-zone requirement** stored in the zone entry: `fishSkill` (the zone's
   fishing level, matching Classic) and `skinSkill` (mob level × 5 for the zone's typical game).
   Ore and herb confidence uses the per-resource requirement from the catalog. The confidence
   function takes `(playerSkill, required, gatherCount)` in every case, so only the source of
   `required` differs.
4. **Gathered but missing from the truth table** (unlisted zone, data gap, rare spawn): the
   resource is recorded and shown as **medium tier, always uncertain**, whatever your skill. The
   "?" never goes away, because there is no true value for skill to reach. `/img known` marks these
   as "unconfirmed" so they can be reported upstream and added to `Data.lua`.
5. **Client API.** Assume Classic Era behaviour (`UNIT_SPELLCAST_SUCCEEDED` with spell IDs,
   `LOOT_OPENED`, `GetLootSlotLink`, `GetSkillLineInfo`). For robustness, match gathering casts
   by **spell name** ("Mining", "Herb Gathering", "Skinning", "Fishing") as well as known IDs.
   `/img debug` toggles printing of each cast and its loot item IDs, so this can be checked in game
   on the first run. Verifying the API in game is the first step of the build. Findings go into the
   WoW: Forever client notes.

## Saved variables

- `ImmerseMeGeographyDB` (account): display settings, same shape as Weather's DEFAULTS.
- `ImmerseMeGeographyCharDB` (per character): discoveries + gathering record.

## Coexistence with ImmerseMe: Weather

- Geography's default arc is `high`, and its readout grows **upwards** from just above the
  minimap's horizontal midline; Weather's default `low` grows downwards. Same `gap` default (10)
  and font size (11) so the two columns line up.
- If Weather is loaded and its `arc` is not `low`, Geography prints a one-time hint suggesting
  `/imw arc low` (my call: don't touch another addon's settings).
- Independent addons: neither depends on the other.

## Settings & commands

`/img` and `/geography` (suite convention `/im<letter>`):
- `show` / `hide`, `rows <0-6>`, `arc high | middle | low`, `gap <0-40>`, `y <-60..60>`,
  `font <8-18>`, `words on|off` (terrain word on row 1), `reset`.
- `known` prints what this character has discovered in the current zone (debug/RP aid).
- `forget zone|all` clears this character's discoveries (with confirmation).

## Art

- `tools/make_icons.py` (pure Python 3, no deps, like Weather's) generates 64×64 32-bit TGAs into
  `Media/`: one icon per land facet value, three tier icons (+ uncertain variants or an overlay),
  and the 128×128 addon-list `icon.tga` in the shared ImmerseMe frame.
- Style: painted, stock-WoW icon feel, warm gold accents matching Weather's badges.
- Resource rows use the item's own game icon (from `GetItemIcon` / the catalog) only in the
  tooltip; the minimap row stays text + tier icon to keep it compact.
- `tools/preview_icons.py` → `docs/images/icons.png` contact sheet.

- Zone data values and flavour text.
- Icon shapes, as long as they read at ~14 px and match the Weather set.
